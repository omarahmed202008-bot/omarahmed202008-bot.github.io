# Omar Ahmed Abdullah — Research Portfolio

Public website: https://omarahmed202008-bot.github.io/

This repository contains the poster-free research portfolio website. The entire site is currently in `index.html`, including the six project case studies. Source posters and scans are deliberately excluded; the portfolio uses original research summaries and diagrams.

## Publish

In repository **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and **Save**. This setting must be enabled in GitHub if it is not already active.

## Edit content

Open `index.html` in the GitHub repository, click the pencil icon to edit, then **Commit changes**. GitHub Pages redeploys changes from `main` automatically after hosting is configured. Search within the HTML for the heading or project title you wish to change. Keep source posters out of public content and downloads.

## Research integrity

Distinguish measured outcomes from targets, simulations, proposals, and unverified claims. Respect collaborators' permissions before publishing team work or identifying materials.
