# Omar Ahmed Abdullah — Academic Portfolio

Public website: https://omarahmed202008-bot.github.io/

A static, accessible academic portfolio hosted on GitHub Pages, covering six source-grounded research case studies, student leadership, honors, CV and contact information.

## Structure

- `index.html` — homepage, research discovery, academic timeline, honors, leadership and contact.
- `projects/*.html` — six detailed research case studies, with source-qualified experimental summaries.
- `cv.html` — professional, responsive CV, printable or saved as PDF using the browser.
- `assets/enhancements.css` — shared accessible and responsive components.
- `assets/enhancements.js` — accessible Ctrl+K search, project architecture explorers, source-data chart views, educational principle sliders, citation copy, and downloadable plain-text summaries.
- `privacy.html` — privacy, accessibility and scientific-evidence disclosure.
- `sitemap.xml`, `robots.txt`, `site.webmanifest` — discovery and site metadata.
- `.nojekyll` — GitHub Pages static-site configuration.

## Research integrity and privacy

The site **does not include original project posters, poster images or poster downloads**. Source findings are transcribed and independently described. Results are labeled as reported data, simulated outcomes, design targets, or educational-only conceptual demonstrations. Individual research contributions and available evidence are stated with their limitations. Some team authorship and original experimental data remain unverified; do not invent them.

The site has **no third-party tracking script or visitor analytics cookies**. GitHub provides aggregate repository traffic analytics through its Insights / Traffic view. The portfolio search runs locally in the visitor's browser.

## Editing the live site

Changes to the `main` branch publish through GitHub Pages when configured under **Settings → Pages → Deploy from a branch → main / (root)**.

1. Edit `index.html` for homepage content, then commit the change.
2. Edit the relevant `projects/<slug>.html` for a project.
3. Edit `assets/enhancements.css` for shared interactive styling and `assets/enhancements.js` for interactive behavior.
4. Update `sitemap.xml` when adding public pages.
5. Verify changes after deployment. Review desktop/mobile views and browser console, check all links and interactions, and ensure each numerical claim remains evidence-backed.

For public research reviewers: use the online case studies and CV. Research source files and certificates requiring collaborators' approval are not part of this public repository.
